# Travel Revenue AI

Внешний интеллект для турагентств, который находит денежные возможности, предупреждает о рисках и превращает рыночные сигналы в конкретные действия.

## Структура проекта

- `backend/` — серверная часть, компоненты системы
- `frontend/` — клиентская часть, интерфейс пользователя
- `database/` — схемы, миграции и конфигурация базы данных
- `docs/` — документация проекта
- `tests/` — тесты системы
- `scripts/` — вспомогательные скрипты

## Документация

- `docs/vision.md` — видение продукта
- `docs/implementation_plan.md` — план разработки MVP
- `docs/system_architecture.md` — техническая архитектура
