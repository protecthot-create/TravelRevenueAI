# Доменная модель Revenue Intelligence

## Основные сущности

| Модель | Назначение |
|---|---|
| `BusinessOpportunity` | Объяснимая бизнес-возможность из одного или нескольких сигналов |
| `RevenueImpact` | Диапазон возможного денежного эффекта и допущения расчёта |
| `RevenueRisk` | Риск потери выручки и действия по его снижению |
| `Recommendation` | Конкретное рекомендуемое действие |
| `OpportunityScore` | Будущая разложенная оценка возможности |
| `OpportunityGroup` | Связанные возможности с общими сущностями |

## Перечисления

- `OpportunityType` определяет характер возможности;
- `RiskType` определяет вид риска;
- `UrgencyLevel` и `ConfidenceLevel` описывают качественные оценки;
- `RecommendationPriority` задаёт приоритет действия.

Все перечисления наследуют `StrEnum`, поэтому их значения стабильно сериализуются как строки.

## Вход и результат

`RevenueIntelligenceInput` содержит:

- идентификатор и тип сигнала;
- копию `raw_data`;
- безопасный `RevenueIntelligenceContext`;
- время получения.

`RevenueIntelligenceResult` всегда валиден, включая пустой результат. Он содержит списки возможностей, рисков, рекомендаций, групп, metadata обработки и ошибок компонентов.

## Изоляция Signal

`Signal` не является моделью Revenue Intelligence. Для перехода из существующего домена используется `RevenueIntelligenceInput.from_signal()`:

1. считываются только необходимые атрибуты;
2. `raw_data` копируется через `deepcopy`;
3. metadata Intelligence также копируется;
4. `score`, `status` и исходный Signal не изменяются.

## Ограничения RC2

Модели описывают структуру данных, но не содержат правил расчёта выручки, оценки рисков, фильтрации или LLM-логики.
