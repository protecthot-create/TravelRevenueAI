# Tests

Тесты Travel Revenue AI. Проверяют корректность работы компонентов и прохождение тест-кейсов.

## Назначение

- Проверка scoring и filtering
- Проверка генерации рекомендаций
- Проверка формирования morning brief
- Проверка тест-кейсов из `docs/test_cases.md`

## Правила

- Тесты покрывают критические пути системы
- Каждый компонент имеет собственные тесты
- Интеграционные тесты проверяют поток данных end-to-end
