# Backend

Серверная часть Travel Revenue AI. Содержит компоненты системы, описанные в `docs/system_architecture.md`.

## Компоненты

- `signal_ingestion/` — сбор сигналов из источников
- `data_normalization/` — приведение сигналов к единому формату
- `revenue_scoring_engine/` — расчёт score и приоритета
- `filtering_engine/` — фильтрация шума и слабых сигналов
- `recommendation_engine/` — генерация конкретных действий
- `morning_brief_generator/` — формирование утреннего брифа
- `feedback_learning/` — сбор обратной связи и калибровка
- `scheduler/` — управление периодическими задачами
- `database/` — доступ к данным и модели
- `api/` — точка входа для frontend и интеграций
- `frontend/` — серверная часть интерфейса (если требуется)

## Правила

- Каждый компонент — отдельная папка с чёткой зоной ответственности.
- Бизнес-логика реализуется внутри компонентов, а не в API.
- Компоненты взаимодействуют через явные контракты.
