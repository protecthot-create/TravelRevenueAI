# Frontend

Клиентская часть Travel Revenue AI. Интерфейс для просмотра сигналов, рекомендаций, утреннего брифа и обратной связи.

## Назначение

- Просмотр morning brief
- Отображение рекомендаций и приоритетов
- Возможность оставить feedback
- Просмотр истории сигналов и решений

## Правила

- Работает через API backend
- Минимальная версия для MVP — простой и понятный интерфейс
- Все пользовательские тексты на русском языке
