# Будущий поток принятия решений

## Статус

Этот документ описывает целевой поток. В RC2 он не подключён к существующему Pipeline, API, Scheduler или сервисам брифинга.

## Целевой поток

```text
Signal
  → RevenueIntelligenceInput.from_signal()
  → OpportunityDetector[]
  → RevenueEstimator / UrgencyEstimator / ConfidenceEstimator
  → RecommendationBuilder
  → OpportunityGrouper
  → RevenueIntelligenceResult
  → отдельный интеграционный адаптер (будущий этап)
```

## Этапы

1. Интеграционный адаптер создаёт независимый input snapshot из Signal.
2. Детекторы формируют доменные возможности.
3. Оценщики добавляют денежный диапазон, срочность и уверенность.
4. Builder формирует действия для каждой возможности.
5. Grouper агрегирует связанные возможности.
6. Engine возвращает результат, включая ошибки отдельных компонентов.

## Правила изоляции

- Engine не обновляет Signal;
- Engine не меняет `raw_data`, `score` и `status`;
- Engine не записывает результат в БД;
- ошибка компонента не прерывает другие этапы;
- решение об отображении, сохранении и включении в morning brief остаётся будущей интеграционной задачей.

## Обратный поток

На следующих этапах возможна передача результата в существующие сервисы только через явный адаптер и после отдельного согласования совместимости контрактов.
