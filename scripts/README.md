# Scripts

Вспомогательные скрипты Travel Revenue AI.

## Назначение

- Запуск компонентов вручную
- Настройка окружения
- Миграции и обслуживание базы данных
- Утилиты для разработки и отладки

## Правила

- Скрипты не содержат бизнес-логику
- Каждый скрипт имеет одну чёткую цель
- Документация по использованию внутри скрипта
