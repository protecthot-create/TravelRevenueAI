# Database

Хранилище данных Travel Revenue AI. Содержит схемы, миграции и конфигурацию базы данных.

## Назначение

- Хранение сырых и нормализованных сигналов
- Хранение score, фильтрационных решений и рекомендаций
- Хранение morning brief
- Хранение feedback и истории действий
- Хранение настроек источников и метаданных задач

## Правила

- Централизованное хранение состояния системы
- Поддержка аудита и воспроизведения решений
- Миграции версионируются
